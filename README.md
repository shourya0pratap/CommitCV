# 📄 CommitCV

**The fully accessible, free-forever resume builder. No ads. No paywalls. Just clean code and perfect PDFs.**

CommitCV is a modern, lightweight, single-page application (SPA) designed to solve the common frustrations of online resume builders. It provides a seamless, real-time editing experience with advanced features like drag-and-drop reordering, GitHub profile auto-fill, and a flawless native PDF export.

## ✨ Features

- **Live Real-Time Preview:** See your resume update instantly as you type.
- **Native PDF Export:** Utilizes highly optimized `@media print` CSS for pixel-perfect A4 rendering, avoiding bloated third-party PDF libraries.
- **Drag & Drop Sections:** Fluidly reorder skills using Framer Motion.
- **GitHub Auto-fill Integration:** Fetch and auto-populate personal details directly from the GitHub public API.
- **Smart Auto-Saving:** State is persistently synced to `localStorage` so users never lose their progress.
- **Dark Mode:** A fully integrated theme toggler.
- **Multiple Experiences:** Dynamically add, edit, or remove work experiences.

## 🛠️ Tech Stack

- **Frontend Framework:** React.js (Vite)
- **Routing:** React Router (DOM)
- **Styling:** Tailwind CSS (v4)
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **State Management:** React Context API

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone [https://github.com/yourusername/commitcv.git](https://github.com/yourusername/commitcv.git)
   ```
2. Navigate to the project directory:
   ```bash
   cd commitcv
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Start the development server
   ```
   npm run dev
   ```
